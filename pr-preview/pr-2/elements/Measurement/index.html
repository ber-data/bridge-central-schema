    Class: Measurement

    A single act/record of measuring one observed property of one feature of interest, yielding one result. This is the union row: NMDC Biosample. values, BASALT product columns, and BASIN-3D observations all project into it. Deliberately EAV-shaped so that lakehouse-wide search ("all nitrate measurements across NMDC, MONet, and watershed timeseries") is a single-table query.
