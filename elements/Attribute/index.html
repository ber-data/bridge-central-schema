    Notes

    • GFF column 9 is a minimal use case, alongside tabular annotations and metadata. This module has no dependency on GFF, Feature, Contig, or a genomic coordinate system.
    • A key is not an identifier; repeated keys can remain separate entries in an ordered list. Consuming models choose attachment and cardinality. Keys are source names, not a controlled vocabulary.
    • Each value of a multivalued source attribute is its own Attribute entry, with the same key, in source order; one entry never holds a joined list.
    • attribute_cv_id and numeric_value follow the NMDC AttributeValue pattern that BERtron and the KBase CDM use (an optional attribute CURIE plus the raw string, with a typed value), which this pair can be projected onto later. key and value keep the source's text.
